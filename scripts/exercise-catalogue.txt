# CalDef exercise catalogue — the source the seed migration is built from.
# Written for CalDef; exercise names are common gym vocabulary and the cues
# are our own wording. No third-party dataset or media is used.

# measure: wr = weight × reps, r = reps only, d = duration, dd = distance + duration
